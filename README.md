# 犬山城さんぽ

国宝・犬山城（愛知県犬山市・現存最古の木造天守）と城下町を、スマホで歩いて巡れる3D散策アプリの試作品。three.js製の単一HTMLです（「大阪城さんぽ」と同じ仕組み）。

- 現代 / 江戸時代（成瀬家の城下町）をメニューの「時代」で切り替え。築城や合戦の体験ツアーはありません
- 天守: 望楼型 三重四階・地下二階。石垣の中の入口から穴蔵（地下2階・地下1階）→1階→2階→3階→4階（高欄の間）へ、急な階段を自分で歩いて上り下りできます。4階の戸口から外の廻縁（まわりえん）を一周できます
- 天守の中: 犬山市の保存管理計画の記載をもとに、穴蔵＝野面積みの石垣と太い梁、1階＝中央の4室（上段の間・納戸の間・第一の間・第二の間）を武者走りが囲む・拭板敷の床・白漆喰の壁・根太天井、上段の間は一段高い畳と格天井、北西・北東に石落としの間、2階＝武具の間と武者走り・三方の武具棚、3階＝南北の唐破風の間（格子窓から屋根ごしに外が見える）、4階＝長押と格天井・歴代城主の肖像（現代）・赤い毛氈（現代）
- 1・2階の窓は本当に開いた連子格子の窓で、外の景色が見えます
- 城山: 本丸・杉の丸・樅の丸・桐の丸・松の丸を坂道でつなぎ、野面積みの石垣。木曽川側は断崖（後堅固の城）
- 現代: 本丸門と券売所、黒門跡・中門跡の礎石、針綱神社、三光稲荷神社（朱の鳥居・ハートの絵馬）、城前広場、城とまちミュージアム、本町通りの町家の店、旧磯部家住宅、どんでん館（車山）、有楽苑（如庵）、木曽川の遊歩道と桜、犬山橋と名鉄電車、鵜飼の舟（夜はかがり火）、夜の天守ライトアップ
- 江戸時代: 本丸の土塀と櫓・本丸門（鉄門）、杉の丸の中門、黒門、松の丸門と成瀬家の御殿（書院に入れます）、三の丸の武家屋敷、大手門の枡形と堀、碁盤の目の城下町と辻ごとの木戸、高札場・火の見櫓・井戸、寺町、総構えの堀と土塁、三光寺、内田の渡しと対岸の鵜沼宿、筏と帆船。人々をタップすると話します
- 入れる建物: 天守（両方の時代）、現代＝旧磯部家住宅・どんでん館・城とまちミュージアム、江戸＝松の丸御殿の書院・本町の呉服屋
- 人物・調度品の切り抜き画像（assets/atlas*.webp）と襖絵・畳など（assets/tiles.webp）は大阪城さんぽと共通です
- 名所の写真は Wikimedia Commons から検索して表示します（撮影者・ライセンスを併記）
- 建物の配置と寸法は簡略な再現で、距離は縮めています。江戸時代の姿は絵図などをもとにした想像を交えた復元です

URLの末尾に `?era=edo` を付けると江戸時代で開きます。
